# Portfolio

A modern and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Overview
This project showcases a professional one-page portfolio with sections for:
- Home
- About
- Skills
- Projects
- Contact

## Features
- Responsive layout for desktop and mobile devices
- Clean and modern UI
- Light and dark theme toggle
- Smooth scrolling and animated section interactions
- Professional contact section and social links

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome Icons

## Project Structure
- Portfolio.html - Main HTML structure
- styles.css - Styling and theme design
- script.js - Interactive behaviors and theme switching
- assets/images/profile.png - Profile image

## Notes
The frontend is fully prepared and polished. Backend functionality is not implemented yet.
